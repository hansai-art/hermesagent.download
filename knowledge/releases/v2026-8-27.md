如果你把 Hermes Agent 當成「有更新就直接跑」的工具，這一版值得先停一秒看清楚：某些 image 或套件管理器安裝現在會拒絕不安全的原地更新。這不是單純修補；它是把 v0.20.5 之後約 525 個已合併 PR 收成供 Docker、代管部署與新安裝使用的穩定標籤[^1]。

官方同時明說，這段期間的完整精選 release notes 會隨 v0.21.0 發布。因此以下只整理 v2026.8.27 已明確寫出的變動；設定細節、相容性範圍與操作步驟沒有被官方展開的地方，一律不補寫。

## 更新不再硬做：不安全的原地更新會被拒絕

對 image 安裝與由套件管理器管理的安裝，更新器新增了拒絕不安全 in-place update 的保護（release notes 指向 #91277 Phase 3）[^1]。如果你原本把 `hermes update` 放進自動化流程，更新被拒絕時不要用其他指令強行覆蓋；先確認這個安裝來源是否應該由 image 或套件管理器本身更新。

官方仍列出既有安裝以 `hermes update` 更新；全新安裝則使用官方 install script[^1]。但這份 patch notes 沒有列出每種受保護安裝來源的判斷條件或替代指令，這部分要等官方文件補充後再寫成教學。

## 長對話的預設行為改了：lean-tail compression

`lean-tail compression` 現在成為預設值[^2]。這影響的是長 session 如何壓縮上下文，不是單一模型供應商的選項。若你有依賴舊壓縮結果、測試 token 用量，或用壓縮後內容做後續流程，更新後應重新跑一次自己的案例，再決定是否調整設定。

官方 release notes 沒有提供開關名稱、壓縮門檻或遷移方式；因此本站不宣稱可以用某個 config 欄位還原舊行為。

## 搜尋、工具選取與遠端 MCP 都擴大了

這一版為 `web_search`／`web_extract` 加入 TTL 結果快取，也讓 `tool_search` 支援多查詢與 stemming[^2]。對日常使用者來說，這代表重複查詢與工具尋找的內部行為有變，但官方沒有承諾特定命中率、速度數字或 TTL 值。

遠端 MCP catalog 也擴增到 50 個以上、經 live verification 的供應商代管 server，release notes 點名 Cloudflare、Grafana Cloud、Better Stack 與 Railway[^3]。目錄有新項目不等於你的現有 MCP 設定需要改；連線方式、授權與個別 server 的權限仍要以各供應商的官方文件為準。

## 瀏覽器、桌面版與秘密資料的保護

官方列出三項容易被既有使用方式碰到的變動：本機瀏覽可在同意後使用預設 Chromium profile；Windows 有 close-with-approval 流程；桌面版 Browser 取得獨立 OS 視窗[^4]。這些都是功能方向，不足以推導出各平台的按鈕位置或是否會自動讀取你的資料，因此請先在非重要 profile 測試。

儲存的 secrets 可選擇使用 OS keychain 加密；release notes 特別提到 macOS 不再每次啟動都跳 Keychain 提示[^4]。它是 opt-in，不是官方宣稱的強制遷移。現有 secret 的遷移時機與指令未在本版 notes 說明。

## 排程與 gateway 的可靠性調整

cron 增加 durable-incident acknowledgement，並讓 code-skew 失敗訊息更清楚；更新器則改為透過 control socket 暫停 gateway，而不是 tree-kill[^5]。如果你靠 cron 或長駐 gateway 做自動化，更新後最值得做的是檢查既有 job 的結果與錯誤訊息，而不是假設舊的故障診斷字串仍然相同。

## 模型選單多了幾個選項

官方列出的新增模型包括 GLM-5.3-Flash、免費的 MiniMax M3，以及 MiniMax H3 Max video[^6]。release notes 沒有列出供應商路由名稱、可用帳戶、價格或地區；在模型選單看見它們之前，不要把它們寫死進設定檔。

## 這一版對你既有的設定有影響嗎

有三件事應優先檢查：

1. **更新自動化**：image 或套件管理器安裝可能不再接受原地更新；讓安裝來源負責更新，不要繞過保護。[^1]
2. **長 session**：lean-tail compression 已成預設；對輸出或 token 行為敏感的流程要重測。[^2]
3. **cron／gateway 與瀏覽器**：錯誤呈現、gateway 暫停方式、瀏覽器 profile 同意流程都可能與舊教學不同。[^4][^5]

其餘功能多屬新增或內部行為調整。官方尚未發布此窗口的完整逐項 release notes，本站也已將 81 篇操作與教學文章列為人工覆核，避免只改日期就宣稱已驗證。
