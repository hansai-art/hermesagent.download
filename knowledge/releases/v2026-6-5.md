在這一版之前，你要跟朋友介紹 Hermes Agent，得先解釋什麼是終端機。2026 年 6 月 5 日發布的 **v0.16.0（代號 Surface）** 之後，你可以直接丟一個安裝檔給他[^1]。

這一版的官方統計是 874 個 commit、542 個合併的 PR、關掉 399 個 issue，其中桌面 App 是**一週內 100 個 PR、159 個 commit** 做出來的[^1]。以下挑對中文使用者最有感的幾項講。

## 桌面版 App：不是終端機的殼

`apps/desktop/` 是一個真正的 Electron 應用程式，在 macOS、Linux、Windows 上像一般軟體那樣安裝，而且能在 App 內自我更新[^2]。

你會拿到的東西：

- 串流顯示的聊天視窗，session 清單可封存與搜尋
- 檔案直接拖進聊天區，剪貼簿圖片可貼上
- Cmd+K 指令面板
- 狀態列直接切換模型

## 繁體中文使用者要知道的一件事

桌面版這一版加了**完整的簡體中文介面**，涵蓋聊天視窗、側邊欄、設定、cron、訊息、profiles、技能等全部 UI[^3]。預設仍是英文，在 Appearance 設定切換後會寫進 `display.language`。

**目前沒有繁體中文。** 這是誠實的說明，不要期待裝好就有台灣用語。好消息是官方是用正規的 typed i18n 層做的，官方原文寫「adding more languages from here is straightforward」（之後要加語言很直接）[^3]，所以繁體中文是可以貢獻的方向，不是要重寫整套架構。

## 桌面版可以連遠端的 Hermes

桌面 App 不一定要在本機跑 Hermes。你可以指向一台遠端 gateway（自架主機、雲端機器、同事的伺服器），透過安全的 WebSocket 連線，用 OAuth 或帳號密碼登入[^4]。

實務上的意義：**筆電只跑一個輕的 GUI，真正吃資源的 agent 跑在你 API 金鑰與算力所在的那台機器上**。每個 profile 可以指向不同的遠端主機，而且同一個視窗能同時跑多個 profile 的 session。

## 網頁後台變成完整管理面板

以前網頁 dashboard 只能看 session。這一版它長成一個完整的管理介面[^5]：

- Channels 頁面：從瀏覽器設定 Telegram、Discord、Slack 等所有訊息平台
- MCP 目錄的啟用停用開關
- 憑證管理、webhook 與 hook 建立、記憶系統設定、gateway 控制
- System 頁面：更新前檢查、一鍵 Debug Share

換句話說，**要接一個新的訊息平台或 MCP server，不用再 SSH 進去改 `config.yaml`**。

## 新手安裝路徑變短

第一次設定被簡化成兩條路[^6]：

- **Quick Setup**：用 Nous Portal 登入，拿到模型選單，直接開始對話
- **Full Setup**：power user 用的完整精靈

`hermes portal` 是跑完整 quick setup 流程的指令別名。官方講得很白：新使用者不該為了送出第一則訊息去讀文件。

## 模型選單支援模糊搜尋

模型選單在桌面版、網頁後台、TUI、CLI 全部支援模糊搜尋[^7]。打 `v4fl` 就會浮出 `deepseek-v4-flash`；多端點的供應商會收合成一列，不再洗版。

模型目錄的更新頻率也從每天改成**每小時**，新模型上線當天就會出現。這一版新增的模型包含 `deepseek-v4-flash`、`MiniMax-M3`（1M 上下文）與 `qwen3.7-plus`[^7]。

## 說錯話可以收回：`/undo`

```text
/undo 3
```

往回收 N 個使用者回合，把你最後一則訊息填回輸入框讓你改了再送，中間的回合軟刪除[^8]。CLI、TUI 與各訊息平台（Telegram、Discord 等）行為一致。

## 預設技能瘦身

內建技能被刻意精簡[^9]。重複或已死的被移除（`spotify` 被原生外掛取代、`linear` 被 `hermes mcp install linear` 取代等），比較重或小眾的從內建改成選配，仍然一個 `hermes skills install` 就裝得回來。

新增的 `environments:` 相關性閘門會把用不到的情境技能（kanban、docker/s6）擋在技能索引外，明確要求時才載入。結果是預設清單更短、提示詞更輕。

另外 NVIDIA/skills 加入 Skills Hub 的預設信任來源，與 OpenAI、Anthropic、HuggingFace 並列[^10]。

## 這一版對你既有的設定有影響嗎

- **預設技能清單變了**：如果你原本依賴某個被移到選配的技能，更新後要手動裝回來
- **預設介面可以選**：`hermes chat` 進 CLI 還是 TUI 現在可以設定，也能用 `--cli` 單次覆蓋[^11]
- **安全更新**：這一版含 CVE-2026-48710 的 Starlette 版本下限、SSRF 強化與子行程憑證剝除[^1]，建議更新
