上一版把 Hermes 放到你的桌面上。2026 年 6 月 19 日發布的 **v0.17.0（代號 Reach）** 處理的是這個觸角能伸多遠：多了兩個對話管道、桌面版變成真的能天天用，以及一個對長任務很有感的改變[^1]。

官方統計約 1,475 個 commit、約 800 個合併 PR、300 多個 issue 關閉、245 位社群貢獻者[^1]。以下挑幾項講。

## 子代理可以丟到背景，你繼續做別的

這是這一版最實際的改變。

```text
delegate_task(background=true)
```

派出去的子代理在背景跑，**立刻回傳一個 handle 給你**，你跟模型都不必等[^2]。子代理做完的那一刻，完整結果會以一個新回合重新進入對話。

實務場景：叫它去做一輪長時間的資料調研，或一個多步驟的建置，然後你自己去忙別的，不用坐在那裡盯著它跑。CLI 與 TUI 的狀態列也會顯示背景子代理的數量[^3]。

## iMessage：不用再養一台 Mac 當中繼

新增了建在 Photon 託管線路池上的 iMessage 平台外掛[^4]：

```bash
hermes photon login
```

用裝置碼認證之後，Hermes 就能收發 iMessage。官方定位它是 BlueBubbles 的接班方案：**不必在櫃子裡放一台 Mac 跑中繼程式，也不必自架橋接**，免費起步。

同一版也接上了 Raft 代理網路，Hermes 可以作為外部 agent 掛進 [Raft](https://raft.build)[^5]。它採用「合約式隱私」設計，喚醒訊息只帶事件 ID 與時間戳這類 metadata，不帶訊息內容。

## 排程不用學 cron 語法

新增了**自動化藍圖（Automation Blueprints）**[^6]。你按名字挑一個自動化，Hermes 反過來問你需要什麼，不用打 cron 語法，也不用記 `slot=value` 的格式。

一份藍圖定義會在每個介面各自渲染成合適的樣子：網頁後台是表單，CLI / TUI / 訊息平台是斜線指令，跟 agent 對話則是一段問答。「每天早上八點給我新聞摘要」變成回答幾個問題就好，不用背 `0 8 * * *`。

## 技能整理的背景成本降到零 token

這一版把一個會默默花錢的東西關掉了。

技能整理器（curator）預設仍會清掉閒置技能，但**那個會呼叫 LLM 做整併的環節改成需要你主動開啟**（`curator.consolidate: true`，或 `hermes curator run --consolidate`）[^7]。純規則的閒置清理繼續免費跑，會花輔助模型 token 的「幫你建立傘狀技能」那一段預設關閉。

日常的背景整理成本因此是**零 token**。如果你之前覺得帳單上有一筆說不出來源的輔助模型花費，這一版值得更新。

## 記憶系統：一次呼叫完成一批修改

`memory` 工具新增 `operations` 陣列，可以把一批新增 / 取代 / 移除的編輯**針對最終字元預算原子化套用**[^8]。

差別在哪：以前模型要「先騰出空間、再寫入」，在多個回合裡拆成好幾次操作，中間任何一步失敗就卡住。現在即使單獨新增會超出預算，也能在同一次呼叫裡先釋放再寫入。記憶更新變快，而且大幅降低寫到一半失敗的機率。

## 桌面版變成可以天天用

上一版剛生出桌面 App，這一版用數十個 PR 把它做深[^9]：

- 可自訂的鍵盤快捷鍵
- 原生系統通知，可依類型分別開關
- **子代理觀察視窗**：把被委派的 agent 活動即時串流到自己的面板
- 輸入區的模型選擇器與逐模型預設值
- 自動判斷 RTL 文字方向
- 可調整大小、套用 VS Code 主題的終端機面板
- 可以直接安裝**任何 VS Code Marketplace 主題**

## 模型與訊息平台

- **Cursor 的 Composer 模型**：`grok-composer-2.5-fast` 進了 xAI OAuth 模型選單，上下文修正為完整 200k。有 xAI Grok 訂閱的人可以直接用，不需要另外的 API 金鑰[^10]
- **官方 WhatsApp Business Cloud API**：除了既有的 Baileys 橋接，現在支援 Meta 第一方託管路徑，不用維持一個掃 QR code 的橋接程式[^11]
- **Telegram 富文本**：改用 Bot API 10.1 的 rich message，格式更好、長訊息處理更乾淨，預設開啟且可關閉[^12]

## 這一版對你既有的設定有影響嗎

- **技能整併預設關閉**：如果你依賴 curator 自動建立傘狀技能，要自己加 `curator.consolidate: true` 把它開回來
- **Telegram 輸出格式改變**：改成富文本是預設行為，若你的下游有解析純文字的流程，值得確認一次
- **網頁後台驗證變嚴**：需要 token 的端點現在會正確回 401，websocket 驗證改用後台服務的 token[^13]。把 dashboard 開到網路上比以前安全，但原本靠鬆散驗證串接的腳本可能要調整
