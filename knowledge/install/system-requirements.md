你想裝 Hermes Agent，但不確定手上這台電腦跑不跑得動。這頁用白話講清楚，不需要你懂任何技術名詞。

**先講結論**：如果你打算讓 Hermes 去用別人家的 AI 服務（多數人的用法），那它本身幾乎不吃資源，**任何一台還在服役的電腦都夠**。真正會擋住你的是作業系統，不是效能。如果你要在自己電腦裡跑 AI，那是完全不同的量級，請直接跳到後面那一節。

---

## 這頁的數字從哪裡來：請先讀這段

這件事必須說在前面，因為它會影響你怎麼看待底下每一個數字。

**官方文件並沒有完整寫過「要什麼硬體」這件事。** 我們把官方有寫的部分整理起來，官方沒寫的部分，由本站自己實測補上。兩種來源在頁面上會分開標示：

| 這頁的內容 | 來源 | 你可以怎麼用 |
|---|---|---|
| 支援哪些作業系統 | 官方文件 | 照著做就對 |
| 要先準備哪些軟體 | 官方文件 | 照著做就對 |
| 在自己電腦跑 AI 要多少記憶體 | 官方文件 | 照著做就對 |
| 不同系統的功能差異 | 官方文件 | 照著做就對 |
| **Hermes 本身佔多少記憶體** | **本站實測** | **參考值，你的情況會不一樣** |
| **要留多少硬碟空間** | **本站實測** | **參考值，你的情況會不一樣** |

**為什麼實測值只能當參考。** 我們是在一台特定的電腦上、用一種特定的用法量出來的。你量到的數字幾乎一定會跟我們不同，因為下面每一件事都會改變結果：

- 有沒有開瀏覽器功能（開了會多吃幾百 MB，跟多開一個瀏覽器差不多）
- 有沒有把它接上 Telegram、Discord 這類聊天軟體，接了幾個
- 同時開著幾個對話
- 對話累積多久了（聊天紀錄會一直長大，硬碟佔用跟著長）
- 裝了哪些額外功能

所以請把實測數字當成**「大概是這個量級」**，不是「一定就是這個數字」。如果你只是想知道「我這台用了好幾年的筆電行不行」，量級資訊就足夠讓你判斷了。

測試環境寫在本頁最後，方便你對照自己的機器。

## 第一步：先確認作業系統，這比硬體重要

官方在[平台支援頁](https://hermes-agent.nousresearch.com/docs/getting-started/platform-support)把作業系統分成三個等級，決定的是「出問題時官方修不修」。

### 官方全力支援

這一級如果出問題，官方會當成第一順位處理，你在這一級最安心。

| 作業系統 | 要注意的事 |
|---|---|
| macOS | **只支援 2020 年底以後的機型**，詳見下方 |
| Windows 10 / 11 | 沒有特別限制 |
| Linux | 官方主要測 Ubuntu 最新版 |
| WSL2 | Windows 內建的 Linux 環境，[微軟官方功能](https://learn.microsoft.com/windows/wsl/install)，免費 |
| Docker | [把程式連同執行環境打包成獨立盒子的工具](https://www.docker.com)，適合架在伺服器上 |

官方對 Linux 的說法是：主流的發行版大致上都能跑，他們只是沒有每一種都測過[^1]。

### 官方盡量支援

這一級官方會維護，但優先度低，可能說壞就壞。

- **Android 手機**：要透過 [Termux](https://termux.dev)，那是一個讓手機能跑 Linux 指令的免費 App
- **Nix**：一種比較小眾的軟體安裝管道

### 官方明說不支援

這一級不是「可能有問題」，是官方直接說不接受相關的修復請求。

**最重要的一條：2020 年以前的 Mac 幾乎都不能用。**

蘋果在 2020 年底換掉了 Mac 裡面的處理器。換之前用的是 Intel 的處理器，換之後用的是蘋果自己設計的晶片，型號從 M1 開始往上排。Hermes Agent **只支援換過之後的機型**[^1]。

這跟你的 Mac 記憶體多大、硬碟多空完全無關。舊機型就是裝不起來，再好的規格也沒用。這是很多人裝到一半才發現的，所以放在最前面講。

**怎麼確認自己是哪一種**：點左上角的蘋果圖示，選「關於這台 Mac」，看「晶片」那一欄。寫 **Apple M 開頭**（例如 Apple M1、Apple M2）就可以裝；寫 **Intel** 開頭就不行。

另外這幾種安裝管道官方也不支援。如果你在別的地方看到這些指令，那是舊的或錯的[^1]：

- `pip install hermes-agent`
- `uv tool install hermes-agent`
- `brew install hermes-agent`
- 透過 AUR 安裝（Arch Linux 的社群套件庫）

正確的裝法只有一種：用官方的安裝檔，或官方提供的那一行安裝指令。各系統的做法見 [macOS](/install/macos/)、[Windows](/install/windows/)、[Linux](/install/linux/)。

## 第二步：你要走哪一條路

這一步決定你需要多少硬體。兩條路的門檻差三倍以上。

**路線 A：讓 Hermes 去用別人家的 AI。**
你申請一個 AI 服務的帳號（例如 [OpenRouter](https://openrouter.ai)、[Anthropic](https://www.anthropic.com)、[OpenAI](https://openai.com)），Hermes 每次要思考時，就把問題送過去、把答案收回來。**AI 在別人的電腦裡跑，不是在你的電腦裡。** 多數人走這條。要付一點使用費，通常一個月幾十到幾百塊台幣，看你用多兇。

**路線 B：在自己電腦裡跑 AI。**
完全不連外，AI 模型整包下載到你的硬碟，運算也在你的電腦裡。不用付使用費，資料也不會離開你的機器。代價是**要一台夠力的電腦**。

不確定選哪個？先走 A。A 跑順了再考慮要不要換 B，兩者隨時可以切換，不用重裝。

---

## 路線 A：借用別人的 AI，幾乎不吃資源

因為思考的工作在別人家做，你這台只負責兩件事：把問題送出去，以及執行 Hermes 要做的動作（讀寫檔案、跑指令、開網頁）。

### 需要的硬體

| 項目 | 需要多少 |
|---|---|
| 記憶體 | 8 GB 就夠 |
| 硬碟 | 留 15 GB |
| 顯示卡 | **不需要** |
| 處理器 | 沒有特別要求 |

### 我們實際量到的數字

以下是本站在一台 MacBook Air M1（8 GB 記憶體）上量的，**只能當參考**[^2]：

| 當下的狀態 | 佔用記憶體 |
|---|---|
| 開著但沒在做事 | 84 MB |
| 剛建立一個對話 | 166 MB（這是尖峰） |
| 問完一個問題、拿到答案 | 100 MB |
| 結束後過五秒 | 40 MB |

換句話說，**Hermes 本身的量級是幾百 MB，不是幾個 GB**。

一個好記的比喻：**把它當成「多開一個瀏覽器分頁」的資源等級來規劃，不是「多開一台虛擬電腦」。**

再強調一次，這組數字是單一對話、沒有開任何額外功能的情況。如果你開了瀏覽器功能、同時掛著三個聊天機器人、開了五個對話，數字會明顯往上加。你該記住的是上面那句比喻，不是 84 這個數字。

### 那顯示卡呢

**路線 A 完全不需要顯示卡。** 內建顯示晶片、沒有獨立顯卡、顯卡很舊，都不影響。

處理器也只影響 Hermes 做事的速度（例如在你的資料夾裡搜尋檔案），不影響 AI 回答的快慢，因為那段在別人家跑。所以如果你覺得回答很慢，通常是網路問題或對方伺服器忙碌，不是你的電腦不夠力。

## 硬碟要留多少

官方沒有寫這件事。以下是本站在 macOS 上量的，**只能當參考**[^2]：

| 項目 | 實際大小 |
|---|---|
| 程式本體 | 2.8 GB |
| 用一陣子之後的完整資料夾（含聊天紀錄與快取） | 7.4 GB |

那個 7.4 GB 是用了一段時間之後的數字，而且**它會一直長大**，因為聊天紀錄會累積。用得越兇長越快。這也是為什麼這個數字最不能當標準看：你用三個月和用三年，差距會很大。

**建議至少留 15 GB。** 只走路線 A 的話這樣很夠。走路線 B 的話，AI 模型本身要另外算，見下一節。

## 路線 B：在自己電腦跑 AI，這裡才真的要看硬體

Hermes 透過一個叫 [Ollama](https://ollama.com) 的免費工具，在你的電腦裡跑 AI 模型。以下**是官方給的規格，不是我們估的**[^3]：

| 項目 | 最低 | 建議 |
|---|---|---|
| 記憶體 | 8 GB | 32 GB 以上 |
| 硬碟 | 5 GB | 30 GB 以上（想放好幾個模型的話） |
| 處理器 | 4 核心 | 8 核心以上 |
| 顯示卡 | 不需要 | NVIDIA 顯卡、顯示記憶體 8 GB 以上，速度差很多 |

### 可以跑哪些 AI 模型

模型有大有小。大的比較聰明但吃資源，小的比較輕巧但比較笨。這是[官方本機模型指南](https://hermes-agent.nousresearch.com/docs/guides/local-ollama-setup)列出的對照表[^3]，完整模型清單見 [Ollama 模型庫](https://ollama.com/library)：

| 模型名稱 | 要多少硬碟 | 要多少記憶體 | 會不會動手做事 | 適合 |
|---|---|---|---|---|
| `gemma4:31b` | 約 20 GB | 24 GB 以上 | **會** | 品質最好 |
| `gemma2:27b` | 約 16 GB | 20 GB 以上 | 不會 | 只能聊天 |
| `gemma2:9b` | 約 5 GB | 8 GB 以上 | 不會 | 快速問答 |
| `llama3.2:3b` | 約 2 GB | 4 GB 以上 | 不會 | 輕量問答 |

### 新手最容易踩的一條：「會不會動手做事」

上表最後那一欄，是整頁最關鍵的資訊。

Hermes 的價值不在於陪你聊天，而在於它會**實際動手**：幫你改檔案、跑指令、開網頁查資料。這件事需要 AI 模型具備一種能力，技術上叫「工具呼叫（tool calling）」。

**不具備這個能力的模型，裝起來會動，但只能跟你聊天，不能幫你做任何事**[^3]。

這就是為什麼「8 GB 就能在自己電腦跑 AI」這句話成立、但會誤導人：能跑，但跑起來的是一個不會做事的版本。你會覺得「Hermes 好像沒什麼用」，但問題不在 Hermes，在模型選錯了。

**所以路線 B 的實際門檻是 24 GB 記憶體**，也就是能跑 `gemma4:31b` 的那一級。低於這個數字，建議直接走路線 A。

### 沒有顯示卡也能跑，但要有心理準備

以下是官方給的速度參考[^3]。這裡的「token」大約等於一個中文字或半個英文單字：

| 情況 | 速度 |
|---|---|
| 中型模型 + 一般 8 核心處理器 | 每秒約 10 個字 |
| 大型模型 + 沒有顯示卡 | 每秒約 2 到 5 個字，**每次回答要等 30 到 120 秒** |

會動，但你要有耐心。沒有顯示卡時還要把「等待上限」調長，否則系統會以為當掉了而中斷。這是設定檔的內容，不是指令：

```bash
# ~/.hermes/.env
HERMES_API_TIMEOUT=1800   # 30 分鐘
```

把這一行加進那個檔案存檔，下次啟動就生效。沒設的話，大模型很容易在答完之前就被判定逾時。

## 軟體環境：幾乎不用你自己裝

這是好消息。**你不需要先裝 Python，也不需要先裝 Node.js。** 很多教學會叫你先裝一堆東西，Hermes 不用。

官方的安裝程式會自動幫你裝好這些[^2]：

| 它會幫你裝的 | 那是什麼 |
|---|---|
| Python 3.11 | Hermes 主程式用的程式語言 |
| uv | 管理 Python 套件的工具 |
| Node.js v22 | 讓它自己開瀏覽器、接 WhatsApp 時需要 |
| ripgrep | 在檔案裡快速搜尋文字的工具 |
| ffmpeg | 處理語音與影片的工具 |

你真正要**自己先準備好**的只有這些[^2]：

| 你的系統 | 要先有 |
|---|---|
| Windows | 什麼都不用，貼一行指令就好，也不需要系統管理員權限 |
| macOS | `git`，一個版本管理工具，多數 Mac 已經有了 |
| Linux | `git`、`curl`、`xz-utils` 這三個 |
| Linux 而且要裝桌面版 | 再加 `build-essential` |

Linux 使用者可以一次補齊：

```bash
sudo apt install git curl xz-utils build-essential
```

**預期輸出**：一串安裝進度，最後回到可以打字的狀態，而且沒有 `E:` 開頭的紅字。如果顯示 `already the newest version`，代表你早就裝好了，那也是正常的。

### 一個小陷阱：Python 太新反而裝不起來

Hermes 需要 [Python](https://www.python.org) 3.11、3.12 或 3.13，但**不能是 3.14**[^5]。

白話講：Hermes 用到的一些底層零件，還沒推出對應 Python 3.14 的現成版本。遇到這種情況，安裝程式會試著當場自己編譯，然後失敗。

如果你的電腦裡預設的 Python 已經是 3.14，**不要自己想辦法降版**，那會弄壞系統上其他依賴 Python 的東西。讓官方安裝程式自己管理它要用的版本就好，它會裝在獨立的地方，不影響你原本的 Python。這也是為什麼官方不建議用 `pip` 安裝。

## 不同系統能用的功能不一樣

即使同樣是官方全力支援的等級，能用的功能也不完全相同。

### Windows

官方在 [Windows 原生指南](https://hermes-agent.nousresearch.com/docs/user-guide/windows-native)的說法是：除了儀表板裡那個內嵌的終端機分頁之外，其他全部都能在 Windows 上直接跑[^4]。

| 功能 | Windows 直接跑 | 裝了 WSL2 |
|---|---|---|
| 命令列與對話介面 | 可以 | 可以 |
| 接 Telegram、Discord、Slack 等聊天軟體 | 可以 | 可以 |
| 排程，讓它定時自動做事 | 可以 | 可以 |
| 讓它自己開瀏覽器 | 可以 | 可以 |
| 在自己電腦跑 AI 模型 | 可以 | 可以 |
| 網頁儀表板 | 可以 | 可以 |
| 儀表板裡的內嵌終端機 | **不行** | 可以 |
| 開機自動啟動 | 可以 | 可以 |

只有那一個分頁不能用，而且它只是方便功能，不影響主要用途。想要百分之百完整，就多裝一層 WSL2。

### Android 手機

可以裝，但有明確限制[^6]：

- 不能用 Docker
- 語音轉文字功能在手機上跑不起來
- 安裝程式會直接跳過瀏覽器自動化的設定，所以手機上它不能自己開網頁

手機比較適合當「遠端遙控」和「聊天機器人」的那一端，不適合當主力工作機。

## 三十秒自我檢查

裝之前跑這幾行，把結果對照上面。

**Mac 使用者**先確認機型能不能裝。開「終端機」App（在「應用程式」→「工具程式」裡），貼上這一行按 Enter：

```bash
uname -m
```

**預期輸出**：出現 `arm64` 就是 2020 年底以後的機型，可以裝；出現 `x86_64` 就是更早的 Intel 機型，不支援。

接著看記憶體和處理器核心數：

```bash
sysctl -n hw.memsize | awk '{printf "%d GB\n", $1/1024/1024/1024}'
sysctl -n hw.ncpu
```

**預期輸出**：兩行數字，例如 `8 GB` 和 `8`。第一行是記憶體，第二行是核心數。

**Linux 使用者**看記憶體和核心數：

```bash
free -g | awk '/Mem:/ {print $2 " GB"}'
nproc
```

**預期輸出**：兩行數字，例如 `15 GB` 和 `8`。如果說找不到 `free` 這個指令，改用 `cat /proc/meminfo | head -1`。

**所有人**都要確認硬碟還有沒有空間：

```bash
df -h ~
```

**預期輸出**：一張表格，看 `Avail` 那一欄，至少要有 15 GB。

**Windows 使用者**不用跑指令。記憶體按 Ctrl + Shift + Esc 開工作管理員，點「效能」看；硬碟開「本機」看 C 槽剩餘空間。

裝完之後，官方有一個[自我檢查指令](https://hermes-agent.nousresearch.com/docs/getting-started/installation)，會把環境問題列出來：

```bash
hermes doctor
```

**預期輸出**：一份逐項檢查清單，正常時每一項都會顯示通過，最後印出它偵測到的安裝方式。有紅字就照它給的提示處理。這個指令要裝完才能跑。

## 常見誤解

**「我的電腦比較舊，應該跑不動吧」**
走路線 A 的話，幾乎不是效能問題，是作業系統問題。真正會擋住你的是 Intel Mac 這種官方明說不支援的組合，不是記憶體不夠。一台好幾年前的筆電，只要系統夠新，通常都能跑。

**「8 GB 記憶體可以在自己電腦跑 AI」**
可以跑，但只能跑不會動手做事的小模型，那樣的 Hermes 只會聊天。要它真的幫你做事，實際門檻是 24 GB 以上。

**「要先自己裝好 Python 和 Node.js」**
不用，而且自己裝反而容易踩到 Python 3.14 那個坑。讓官方安裝程式處理就好。

**「沒有顯示卡就不能用」**
路線 A 根本不需要顯示卡。路線 B 沒有顯示卡也能跑，只是每次要等比較久。

**「你們寫 84 MB，那我照這個數字規劃就好」**
不建議。那是單一對話、沒開任何額外功能的實測值，它只能告訴你「量級是幾百 MB 而不是幾個 GB」。你實際會用多少，取決於你開了什麼功能、掛了幾個聊天機器人、同時開幾個對話。請用量級判斷，不要拿單一數字當規格。
